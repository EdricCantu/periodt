offset calibration

Set the time for the next bell is expected to ring.
Press the ⏺️ button to begin recording. The number changing rapidly represents the offset from the time the bell should ring, and now.
When a bell sound is detected from the microphone, the number will freeze instantly and turn yellow. If the bell persists for ~5 seconds, it is a period changing bell. The offset will turn green. If not, the offset will turn red for one second, then black, and unfreeze as if nothing happened.
The offset, once green, represents the offset of the bell system's clock from real time.
